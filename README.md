# SmartFridge Android starter

A starter Android project for HTC One M8 / Android 6.0 (minimum SDK 23).

## Build an APK
Use Android Studio or the included GitHub Actions workflow (`Build SmartFridge APK`) to build a debug APK.

## Current starter features
- Local, offline inventory saved on the device
- Fridge/freezer locations
- Add, edit, delete and adjust quantities
- User-set minimum quantities and low-stock shopping list
- Manual shopping list

## Not implemented yet
Barcode scanning, online product lookup, AI produce recognition, cloud backup and synchronisation. These require additional implementation and testing. This starter is not production-ready.
